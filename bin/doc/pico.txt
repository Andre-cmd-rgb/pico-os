The pico language
=================

C-like, statically typed, with automatic memory and
no pointers. A mistake stops with the line it
happened on rather than corrupting something.

  pico hello.pico     compile and run
  picoc hello.pico    compile to ./hello

A PROGRAM

  int main(str[] args) {
      str who = len(args) > 1 ? args[1] : "world";
      println("hello ", who);
      return 0;
  }

TYPES

  int     32-bit signed        float   32-bit
  bool    true or false        str     UTF-8 text
  T[]     growable array       struct  named fields
  File    an open file         void    no value

  struct Point { int x; int y; }
  Point p = Point{x: 3, y: 4};
  int[] xs = [1, 2, 3];
  int[][] grid = [[1, 2], [3]];
  enum Dir { UP, DOWN, LEFT = 10, RIGHT }
  Dir d = LEFT;           an enum's values are ints

CONTROL

  if / else, while, for (int i = 0; i < n; i++),
  break, continue, return, and ? :

  for (str s in names) println(s);   each item
  for (str ch in chars(text)) ...    each character

  switch (key) {
  case 'q', KEY_ESC: quit();         no falling
  case KEY_UP: y--;                  through; break
  default: beep();                   leaves it
  }

STRINGS

  len substr find split join trim upper lower replace
  starts_with ends_with contains repeat chr ord
  chars to_int to_float str
  s[i] is the byte at i. "n=" + n builds text.

ARRAYS

  len push pop insert remove_at resize slice sort
  reverse find

MATHS

  abs min max sqrt pow sin cos tan atan2 hypot exp
  ln floor ceil round random seed
  PI INT_MAX INT_MIN

FILES AND THE SYSTEM

  open close read readline write exists is_dir remove
  mkdir rename listdir
  stdin stdout stderr are File constants.
  run getenv exit sleep_ms uptime_ms time date
  raw_mode readkey term_cols term_rows
  output("date")      what a command prints, as a str

THE INTERNET

  http_get(url)          a page or an API's answer
  json_get(j, "a.b.0")   one value out of JSON; the
                         path's "#" counts the items

  str j = http_get("https://...");
  println(json_get(j, "current.temperature_2m"));

CHECKING THINGS

  assert(cond)             stops at the line if false
  assert(cond, "why")      and says why

PRINTING

  print println printf format
  printf checks its arguments when the format is a
  literal, at compile time.
