Commands
========

`help NAME` explains any of these in detail.

FILES
  ls cat cp mv rm mkdir rmdir touch pwd stat
  df du mount umount sync mkfs realpath edit
  find DIR -name '*.txt'   look for files; -type,
                    -size, -mtime, -exec, -delete
  push/pull are on the PC side (see `man intro`)

TEXT
  head tail wc more hexdump cmp
  grep PATTERN      regular expressions: -E -i -v
                    -w -x -o -n -c -l -r -A -B -C
  sed 's/old/new/g'  edit text as it goes by; -i
                    edits files in place, -n with p
                    picks lines: sed -n '/todo/p'
  sort uniq cut tr tee
  diff -u A B       what changed between two files
  sha256sum FILE    also md5sum sha1sum sha512sum and
                    cksum; -c checks a saved list
  xargs CMD         run CMD on the words coming in:
                    find . -name '*.bak' | xargs rm

NOTES
  notes             pick one from ~/notes (a folder
                    per subject): Markdown or text,
                    laid out for the screen
  notes FILE        read it: space/b pages, o the
                    headings, / finds, + and - the
                    backlight, q quits. Each note
                    reopens where you left it

DIARY
  alarm             what is set, and when it rings
  alarm 7:00 mo-fr wake up
                    repeats: daily, weekdays,
                    weekends, mo,we,fr; a date
                    (tomorrow, 30/9) rings once
  alarm 25m tea     a timer
  alarm rm|off|on N, alarm stop|snooze|test
                    Ringing, any key snoozes it for
                    9 minutes and Esc stops it;
                    suspend wakes up for it
  todo              the to-do list, ~/todo.md
  todo add TEXT @fri  also @today, @30/9, @+3;
                    todo done N, todo clear
  calendar          the month: arrows, a adds, d
                    deletes; the day's events and
                    what is due from ~/todo.md
  calendar agenda   the week ahead
  calendar add 30/9 10:00 verifica !15
                    !15 chimes 15 minutes before;
                    every mo,we ... / yearly 2/10
  cal [-3] [year]   print a month, or a year

SCRIPTS
  echo printf seq expr test basename dirname
  true false sleep yes env
  type NAME         what a command name is
  set -e -u -x      stop on errors, trace commands
  trap 'CMD' EXIT   run CMD at the end; also INT TERM
  alias ll='ls -l'  a short name for a command

JOBS
  CMD &             run CMD in the background
  Ctrl-Z            stop the program in front
  jobs              what is stopped or behind
  fg [%N] / bg [%N] bring one to the front / let it
                    go on behind; kill %N ends it

SYSTEM
  ps top kill free dmesg uptime uname date time
  whoami hostname
  sleep env which clear reboot chvt screenshot
  i2cdetect keytest bench lcdtest backlight
  rotate      turn the screen upside down (again:
              back); rotate 0 / rotate 180

LOOKS
  theme             the colours now, and a swatch
  theme list        every theme (dark and light)
  theme gruvbox     switch; `light`, `dark` after
                    the name, or alone, switch half
  theme auto 7:00 20:00   light by day
  theme set bg #1d2021    a colour of your own:
                    fg bg dim bold bar bar-text
                    cursor, red..., bright-red...
  theme reset       drop your own colours
  theme cursor block|underline|bar
  theme blink on|off, theme bar top|bottom
  All kept in /etc/theme.

POWER
  battery     level, what it is doing, time left,
              cycles; -v everything: current,
              calibration, health; -l the power
              log (starts, sleeps, each half hour);
              -m 4.12 what a meter reads on the
              cell; -c MAH a new cell fitted
  power       policy, locks, where the time went;
              power dim 3m blank 4m suspend 15m
              (never = off; kept in /etc/power)
  cpufreq     performance | ondemand | powersave
  suspend     deep sleep until any CardKB key
              (or the side button, -t, an alarm);
              waking is a fresh boot
  Ctrl-A z    doze, from anywhere: the screen and
              radio off, everything kept; a key
              brings it back where it was (Fn 0
              on the CardKB, or Fn A then Z)
  Fn 5 Fn 6   brightness down, up; Fn 9 mute,
  Fn 7 Fn 8   volume down, up. Kept for the next
              boot, as backlight and volume are
  poweroff    deep sleep until Enter on the CardKB
  led         the charge light: lit while it
              charges, green when full
  No key for 3 minutes dims the screen, 4 turn it
  off (the key that lights it does nothing else);
  15 with nothing running suspends.

SOUND
  play FILE   WAV, FLAC, MP3, or raw 16-bit mono;
              plays on while a game or a clip on
              another terminal makes its own sound
  play -n F   decode without playing: speed and a
              checksum, for testing
  rec FILE    record from the microphone
  beep [hz] [ms]
  volume [0-100]

NETWORK
  wifi              what the radio is doing
  wifi scan         what is in range, numbered
  wifi connect #2 PASSWORD
  wifi forget NAME / disconnect / on / off
  ntp               set the clock now (Wi-Fi also
                    sets it whenever it connects;
                    `make time` on the PC sets it
                    too)
  ping [-c N] HOST
  wget URL          fetch a file; -c goes on after a
                    break, -O names it
  curl URL          what an address returns: -L
                    follows, -I headers, -d posts
  modem             the SIM module, if one is wired
  modem on, off     its radio (off: 0.7 mA, nothing
                    heard), kept across restarts
  modem scan        the networks it can hear
  modem apn NAME    the network's data service name
  modem ussd *123#  ask the network: credit, offers
  sms               text messages
  passwd            set the password the network
                    shell asks for (-d removes it)
  A shell is also waiting on port 23 (telnet), so
  the board can be used over the network with the
  USB port free. Nobody gets in until a password
  is set.

VIDEO
  video             pick a clip from ~/video
  video CLIP.ptv    play it; space pauses and shows
                    where it is, s saves a frame,
                    q stops
  Left/right        10 s back or on; up/down a minute
  0-9               0% to 90% of the way in
  A clip goes on from where it was stopped; 0 at the
  question starts it again.
  video -i CLIP     index an older clip: quick jumps
  On the PC: make video FILE=something.mp4

PICTURES
  view              pick one from ~/photos
  view FILE...      BMP or baseline JPEG, scaled to
                    fit; left and right move between
                    them, s saves a copy of the
                    screen, q quits

GAMES
  nes               pick a game from ~/roms
  nes ROM.nes       a NES emulator; q quits, p saves
                    a screenshot
  pad on            the Bluetooth radio
  pad scan          look for a gamepad
  pad connect N     join one
  pad watch         see what a pad sends, to map it
                    in /etc/gamepad

THE PICO LANGUAGE
  pico FILE.pico    compile and run in one step
  picoc FILE.pico   compile to an executable
  See `man pico`.
